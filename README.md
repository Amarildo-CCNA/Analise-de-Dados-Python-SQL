# README para Usuários. Instruções para instalação e execução.
Para a execução, basta fazer o Download da pasta Miniprojeto, de preferência no Google Drive, 
ter uma conta no google.com, acesso ao Google Drive e Google Colab.
Uma vez que se tanha uma conta na Google, basta buscar com google colab, seguir o link e fazer o logon.
Abra o Google Drive, crie uma pasta com nome intuitivo para armazenar seu projeto. Entre na pasta recém
criada, clique com o botão direito do mouse em um espaço em branco da pasta e escolha "Mais" selecione
Google Colaboratory. Caso você ainda não tenha utilizado o Google Colaboratory, no fim do Menu, clique
em "Conectar mais Apps". Escolha o Google Colab e clique em "Instalar". Após alguns segundos, abra o 
Google Colab e, em vá em "Arquivo" "Selecionar do Drive" selecione e dê um duplo clique no arquivo 
"Miniprojeto_Amarildo_Xavier_Marchi_Analise_de_Dados_T1.ipynb". Pronto agora é só percorrer as células e 
executar os códigos. Não se esqueça de executar as célular de forma sequencial, pois existem variáveis
e dependências que precisam ser criadas nas primeiras células para estar a disposição na execução da 
célula subsequente. Caso alguma célula retorne erro na execução, execute-a, novamente.
